# 🚀 mega Timka (меме)

Генератор мемов на Flask: загрузка изображения по прямой ссылке, галерея локальных тем из `image/`, верхняя и нижняя надписи шрифтом Oswald и скачивание PNG.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Открой http://127.0.0.1:5000

Для галереи «🎨 Темы» добавь изображения JPG, PNG, WEBP или GIF в папку `image/`.

Для интернет-картинок нужна прямая ссылка на файл изображения. Некоторые сайты блокируют встраивание или экспорт PNG из-за CORS.

**Важно:** GitHub Pages не запускает Flask. Для публичного работающего сайта нужен хостинг Python-приложений.
